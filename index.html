Engineering notes

Animation is behavior.

01 / Timing

Duration changes perceived urgency. Very fast loops can feel noisy; very slow loops can feel stalled.

02 / Easing

Linear works naturally for rotation. Ease curves suit pulsing and dot sequences better.

03 / Motion safety

Reduced-motion mode suppresses continuous movement and preserves a static loading cue.

04 / Semantics

The loader has status semantics and a text label, so meaning does not depend on animation alone.
